# Descrición

Escena donde un xogador chamado Banana Man, se pode mover nos eixes x e z.

Un raposo chamado Foxy, que siempre lle da a cara a Banana Man, pero sempre mantendo unha distancia de "seguridad", tanto cerca como lonxe, si está máis cerca desa distancia mínima, Foxy alonxase do xogador, si está máis lonxe da distancia máxima, acércase. Si Banana Man se gira, Foxy gira para mirar de frente, sempre mantendo a distancia de seguridad.
